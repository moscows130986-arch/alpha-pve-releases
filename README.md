# ALPHA • РУБЕЖ

Выпуски лаунчера и клиентского пакета ALPHA для **7 Days to Die**.

## Скачать

Готовые файлы размещаются в разделе [Releases](https://github.com/moscows130986-arch/alpha-pve-releases/releases). Отдельный сайт и аккаунт GitHub для скачивания опубликованных файлов не нужны.

**Клиентская часть находится в разработке.** Пока стабильного клиентского выпуска нет. Версии с отметкой **Pre-release** предназначены для согласованного теста и не заменяют стабильную серверную сборку автоматически.

## Как будет работать установка

1. Скачать архив лаунчера из подходящего выпуска и распаковать целиком.
2. Запустить `AlphaLauncher.exe` и указать установленную игру из Steam.
3. Проверить совместимость и установить клиентский пакет кнопкой обновления.
4. Запустить игру через лаунчер и подключиться к серверу ALPHA.

Лаунчер размещает клиент ALPHA в отдельном пользовательском профиле и проверяет подпись пакета и целостность файлов. Папка установленной игры не используется для установки клиента. Моды, ранее установленные в самой игре, могут по-прежнему загружаться игрой.

Точную версию игры, требования и ограничения указываем в описании каждого выпуска. Серверный пакет и клиентский пакет должны соответствовать друг другу.

## Что находится здесь

- Архив лаунчера с настройками обновления.
- Подписанный файл версии и клиентский архив.
- Инструкции, изменения и контрольные суммы выпусков.

Файлы самой игры, сохранения, административные настройки сервера и закрытый ключ подписи здесь не публикуются.
